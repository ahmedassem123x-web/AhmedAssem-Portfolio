# Real campaign data — intake sheet
# ورقة إدخال بيانات الحملات الحقيقية

**Purpose / الهدف:** Your portfolio currently shows **demo data** on the five campaign boards
(Awareness · Engagement · Traffic · Leads · Sales). Fill in this sheet with your **real**
campaign results and send it back — every number you provide will replace the demo data,
nothing else on the site changes.
المعروض حاليًا في موقعك بيانات تجريبية. املأ هذه الورقة بنتائج حملاتك **الحقيقية**
وأرسلها — سأستبدل البيانات التجريبية فقط، دون أي تغيير آخر في الموقع.

**Where to get the numbers / من أين تجلب الأرقام:**
Open **Meta Ads Manager** (or Google Ads) → select the campaign → set the date range →
*Columns: Performance* (or customize columns). Copy the exact figures you see.
افتح مدير إعلانات ميتا (أو إعلانات جوجل) → اختر الحملة → حدّد الفترة الزمنية →
أعمدة الأداء. انسخ الأرقام كما تظهر تمامًا.

**How to fill / طريقة التعبئة:** Write in English or Arabic — either is fine.
اكتب بالإنجليزية أو العربية — الاثنان مقبولان. Leave blank anything you don't have.
